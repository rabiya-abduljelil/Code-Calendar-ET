What is CodeCalender ET?

A site that collects every tech event and hackathon in Addis for CS students

What you can find on this website?

  • Hackathons
  • Bootcamps
  • CTF
  • Internships
  • Tech meetups

How it works?

  1. Create acocunt
  2. Go to events page
  3. Pick event you would like to participate in
  4. Click the register button
  5. You will get notified for all the events you have registered
